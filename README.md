# Fairfax City First Website

A standalone landing page for **Fairfax City First**.

- **Live site:** https://fairfaxcityfirst.com
- **Hosted on:** GitHub Pages
- **Domain CNAME:** `fairfaxcityfirst.com`

## Structure

- `index.html` — Single-page site with hero, mission, candidate cards, and upcoming events.
- `images/logo.png` — Fairfax City First logo.
- `CNAME` — GitHub Pages custom domain configuration.

## Updating events

Open `index.html` and edit the `Upcoming Events` section. Uncomment the example event block and duplicate it for additional events.

## Deployment

Push to the `main` branch of `norrin302/fairfaxcityfirst-site`. GitHub Pages builds automatically.

```bash
GIT_SSH_COMMAND="ssh -i ~/.ssh/id_ed25519_norrin302_github" git push origin main
```
